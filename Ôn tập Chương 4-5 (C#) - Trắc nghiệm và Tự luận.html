📘 Sổ tay lý thuyết nhanh (Chương 4 & 5)

1. Bốn vòng lặp

  • while (đk) { } — kiểm tra điều kiện trước, có thể chạy 0 lần.
  • do { } while (đk); — kiểm tra sau, luôn chạy ít nhất 1 lần, kết thúc bằng dấu ;.
  • for (khởi tạo; đk; bước nhảy) { } — thứ tự: khởi tạo → đk → thân → bước nhảy → đk → … Dùng khi biết trước số lần lặp.
  • foreach (var x in tập hợp) { } — duyệt từng phần tử, không có chỉ số, không sửa được giá trị phần tử.
  • Điều kiện của while / do-while / if phải là bool (C# không cho while(1)).

2. break / continue

  • break — thoát hẳn vòng lặp (hoặc thoát switch) gần nhất.
  • continue — bỏ qua phần còn lại của lần lặp hiện tại, sang lần kế tiếp.
  • Quên cập nhật biến điều kiện trong while → vòng lặp vô hạn.

3. Rẽ nhánh

  • if (đk) { } — điều kiện là biểu thức bool; C# không có then.
  • if … else if … else — mỗi nhánh chỉ có một else, và else luôn gắn với if gần nhất chưa có else.
  • switch (biến) { case gt: … break; default: … } — chỉ dùng với int, char, string, enum…; không dùng với double/float/decimal, không dùng điều kiện phức tạp (x > 5).
  • Thiếu break → fall-through: chạy tiếp các case bên dưới.

4. Mẹo truy vết code

  • Kẻ bảng: lần lặp | biến | điều kiện | kết quả — chạy tay từng bước, đừng đoán.
  • Chú ý tiền tố/hậu tố: x++ dùng giá trị rồi mới tăng, ++x tăng rồi mới dùng.
  • Chú ý điều kiện biên: < hay <=, bước nhảy i++ hay i+=2.
  • int chia nguyên: 5/2 = 2; % là chia lấy dư — dùng để kiểm tra chẵn/lẻ, ước số, chữ số.
